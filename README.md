# Umami Server Academy — Prototype 0.1

Mobile-first Pokémon-inspired RPG-style menu-training prototype for House of Umami.

## Run and publish
The JSON question data loads with `fetch`, so run from a local static server or publish with GitHub Pages. Upload the contents of this folder to the repository root. In GitHub, open **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.

## Prototype safeguards
- Original CSS-drawn ramen artwork; no Pokémon characters or assets.
- Initial quiz uses only information visible on the supplied ramen wall chart (dish names, chart sections, allergen-category labels) plus safe allergen-verification behavior.
- Does not assert unconfirmed ingredients, allergen markings for individual dishes, prices, dietary classifications, or specific menu pairings.
- Guest Battle scenarios demonstrate recommendation judgment without inventing a specific menu pairing.
- XP is stored in browser localStorage. It is not a shared employee leaderboard.
- This prototype does not replace House of Umami allergen procedures.
